# KernelSU-Next для Samsung Galaxy A52s (SM-A525F)

**Устройство:** Samsung SM-A525F (`a52q`)  
**Прошивка:** crDroid Android 16, выпуск 12.12  
**Ядро:** Linux 4.14.357  
**KernelSU-Next:** UAPI 7; Manager 3.4.2 (33355), пакет `com.rifsxd.ksunext`

[English version](README.md)

> Проект предназначен только для указанной модели и прошивки. Не используйте его на другом устройстве или ROM. Загрузочный образ не проверялся на физическом телефоне. Перед установкой сохраните текущий рабочий boot-образ и убедитесь, что знаете способ его восстановления.

## Содержимое проекта и статус публикации

В состав исходного дерева должны входить `kernel/` и `KernelSU-Next/` с сохранёнными лицензиями upstream-проектов. Исходники ядра основаны на коммите `673b80046ab92a5823fe10181f06be31382ea041`, KernelSU-Next — на `0c9c4438a6273c5bd80c9fd8816a4c9801e108fe`.

Полный архив исходников пока не прикреплён к этому репозиторию. В переданном архиве есть сгенерированные объектные файлы и кэш Android CMake; перед публикацией их нужно исключить, чтобы не выкладывать результаты сборки. Здесь нет boot-образа, APK и приватного ключа подписи.

Изменения предназначены для KernelSU-Next UAPI v7. Они добавляют окно root-запроса с тайм-аутом 30 секунд и вариантами разрешения: один раз, 10 минут, 30 минут или навсегда. Окно и выдача разрешений **не проверялись на физическом телефоне**; мы не утверждаем, что root-диалог работает.

## Зависимости

Нужна Linux-среда для сборки Android-ядра, `make`, стандартные зависимости сборки ядра, Clang 21 и AArch64 GCC cross-toolchain (`aarch64-linux-gnu-`). Команды ниже выполняются из каталога `kernel/`.

## Сборка

Настрой конфигурацию ядра устройства:

```sh
make O=out ARCH=arm64 LLVM=1 LLVM_IAS=1 CROSS_COMPILE=aarch64-linux-gnu- \
  CLANG_TRIPLE=aarch64-linux-gnu- vendor/lineage-a52q_defconfig
```

Собери сжатый образ ядра:

```sh
make O=out ARCH=arm64 LLVM=1 LLVM_IAS=1 CROSS_COMPILE=aarch64-linux-gnu- \
  CLANG_TRIPLE=aarch64-linux-gnu- \
  KSU_VERSION_OVERRIDE=33355 KSU_VERSION_TAG_OVERRIDE=v3.4.2 \
  KSU_MANAGER_PACKAGE=com.rifsxd.ksunext KSU_NEXT_MANAGER_SIZE=791 \
  KSU_NEXT_MANAGER_HASH=25586317e06049d54e7c2f35ccb71ec06254cdad56db38f1cde09f44e3982b05 \
  -j12 Image.gz
```

Конфигурация включает `CONFIG_MODULES=y`, но ни один драйвер не собран как модуль, поэтому файлов драйверов `.ko` нет: они встроены в ядро. Результаты сборки (`Image.gz`, `vmlinux`, `System.map`, `.config` и другие) должны оставаться локально — не добавляй их в Git.

Воспроизводимость чистой сборки для этой публикации отдельно не проверялась. Считай команды проверенными только после успешного запуска в указанной среде.

## Установка

В этом репозитории нет boot-образа и APK. Собери ядро и подготовь boot-образ для своего устройства и прошивки; Manager собери или получи отдельно. До прошивки сохрани текущий boot-образ и проверь способ восстановления. Используй только подходящий для устройства способ прошивки: обычный `.img` — не пакет `.tar` для Odin. Если телефон не загрузится или root не заработает, восстанови резервную копию.

Пакет Manager: `com.rifsxd.ksunext`, версия 3.4.2 (33355), UAPI 7. Упоминаемый APK подписан локальным debug-сертификатом; **приватный ключ подписи не включён**. SHA-256 сертификата:

```
25586317e06049d54e7c2f35ccb71ec06254cdad56db38f1cde09f44e3982b05
```

Android не разрешает обновить приложение поверх версии с другой подписью. Если локально пересобранный APK подписан другим ключом, может потребоваться удалить установленный Manager; параметры размера и SHA-256 APK в ядре также должны соответствовать используемому APK.

## Известные ограничения

- Ни boot-образ, ни окно root-запроса не проверялись на физическом телефоне.
- Воспроизводимость сборки для этой публикации не проверена.
- При указанной конфигурации драйверы `.ko` не ожидаются.
- Boot-образы, APK, сгенерированные результаты сборки и приватные ключи намеренно не включены.
- Не прошивай это ядро на устройства, отличные от SM-A525F (`a52q`) с crDroid 16 / 12.12.
